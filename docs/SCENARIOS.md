# SCENARIOS · 神经纤维瘤病工作台（小纤宝 FibroPal）

> 患者视角场景清单。每条功能线的核心是患者的关键信息维度，挂一句患者原话（本版为**改写示意句**，非一手引语；0 访谈，如实声明，见 USER-RESEARCH）。

## S1 确诊初期：把病种和该挂哪个科弄清楚（NF1 / NF2 / 施万细胞瘤病）
- 患者（改写示意）：「医生说了个神经纤维瘤病，我回家一搜出来三种，到底我是哪一种、以后该挂哪个科？」
- 信息维度：病种分型（NF1 / NF2 相关施万细胞瘤病 / 施万细胞瘤病）、受累系统清单、首诊科室与转介科室。
- 功能线：病种档案（分型记录 + 受累系统清单 + 来源语境栏）。

## S2 终身随访：各年龄段该查什么（NF1 儿童起病为主）
- 患儿家长（改写示意）：「每次复诊都是想起什么查什么，有没有一张按年龄排的表告诉我现在该做什么？」
- 信息维度：分年龄段随访项目（儿童期身高/血压/发育/视力、青春期、成年疼痛与影像复查节奏）。
- 功能线：分年龄段随访日历（每项带指南来源与版本，无判读列）。

## S3 瘤体档案：哪个瘤在变化
- 患者本人（改写示意）：「身上几十个瘤，纸本子记了两页就乱了，复诊时说不清哪个长大了。」
- 信息维度：瘤体编号、部位、测量方式、尺寸序列（日期 + 数值）。
- 功能线：瘤体档案 + 尺寸趋势折线（仅展示测量值，不做良恶性判读；分类项不进趋势）。

## S4 NF2 听力线：变化过程说不清
- 患者本人（改写示意）：「听力是一年一年慢慢差的，医生问我什么时候开始的、最近一次查是多少，我答不上来。」
- 信息维度：听力分级/听力图关键值（如纯音听阈）、耳鸣记录、日期序列。
- 功能线：听力与症状时间序列 + 指标系列卡（有序、分系列、3D 翻转卡 + 趋势折线）。

## S5 治疗线：MEK 抑制剂（如司美替尼）与手术
- 患者本人（改写示意）：「吃这个药皮肤反应反反复复，哪次加重、什么时候缓解，我自己都记不清。」
- 信息维度：治疗线（手术/药物）、剂量变更、副作用（皮肤/眼部等）发生与缓解时间。
- 功能线：治疗线折叠卡（32 号模版）+ 副作用日常记录。

## S6 疼痛管理
- 患者本人（改写示意）：「疼起来才知道记，复诊时让打分，我说不出上个月平均几分。」
- 信息维度：NRS 疼痛评分、部位、诱因、镇痛用药。
- 功能线：疼痛时间序列（数值进趋势，部位/诱因为分节字段）。

## S7 遗传与家系：该问什么
- 家属（改写示意）：「想再要一个孩子，又怕传给孩子，但不知道去医院该问谁、问什么。」
- 信息维度：遗传咨询就诊问题清单、家系成员记录（仅记录，无风险判读）。
- 功能线：遗传咨询问题清单（每条挂来源）+ 家系成员建档。

## S8 复诊准备
- 患者本人（改写示意）：「见医生只有十分钟，我想把要问的、要报告的先理成一页。」
- 信息维度：间隔期内症状变化、指标变化、问题清单。
- 功能线：复诊准备材料生成。

## 医生任务冒充患者（一票否决项自查）
- 本清单各场景均以患者/家属的信息困惑为出发点（"该查什么/哪个在变/该问什么"），不含医生侧诊疗决策任务（分期裁定、方案选择、剂量核定）。独立评审时按此口径复核；若发现任一功能线实为医生任务包装，视为一票否决项。
