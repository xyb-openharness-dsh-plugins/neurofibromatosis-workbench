# 项目规格 v0.1 · 小纤宝 FibroPal 神经纤维瘤病工作台

状态：草案（M0 骨架版）。确认人/日期：待补（G1 签认）。不得把本模板当成已确认业务。

## 设计者与研究/场景依据

依据 DESIGN-PROMPT 与 DESIGNER-BRIEF 流程；用户需求证据与专业约束分开记录（USER-RESEARCH 证据分层：**0 访谈**，H1–H5 为假设）。场景脚本见 SCENARIOS.md（S1–S8，原话为改写示意句）。癌种项目不把医生任务当患者功能；S1–S8 均为患者/家属信息任务。

## 问题、用户与最小闭环

- 用户：NF 患者/家属双主体（NF1 患儿家长代记 + 成年/NF2 自助）。
- 问题：多系统受累终身随访信息碎片化——不知道该查什么、哪个瘤在变、听力/疼痛过程说不清、副作用时间线记不住、遗传咨询不知道问什么。
- 最小闭环（对应 coreFlow）：导入资料 → 核对候选建瘤体档案与指标基线 → 按分龄日历记录复查 → 记录疼痛/听力/用药线 → 生成复诊与遗传咨询准备材料。
- 失败恢复：候选信息未核对不入档；草稿保存/取消见设置页设计。

## 方案与 ADR

- 布局 business-first（0.65 主区），Agent 右侧面板（20 号）；多瘤体/多指标以"系列分组"而非平铺列表为主结构——NF 与肿瘤样板最大的结构差异：**分年龄段纵向日历 + 多瘤体并行档案**。
- ADR-1：随访日历按年龄段分节渲染（儿童/青春期/成年），而非按科室；依据 S2。
- ADR-2：瘤体档案以编号为聚合键，尺寸趋势按编号分曲线，不做任何良恶性文案；依据红线。
- ADR-3：听力指标进数值趋势（dB HL），耳鸣等分类症状只做分节记录；依据"分类不进趋势"。

## 功能范围

L1 病种档案 / L2 分龄随访日历 / L3 瘤体档案+趋势 / L4 指标系列卡（3D 翻转 + 折线，一图秀带指标选择窗口）/ L5 治疗线折叠卡（32 号）/ L6 遗传家系（问题清单+成员建档）/ L7 复诊准备。详见 docs/FEATURE-INVENTORY.csv（M2 落格）。

## 数据与 API

见 SCHEMA.md / API-CONTRACT.md；核心红线：无 diagnosis/risk_level 类判定列；ORDER BY rowid；显式 null；in_use；分节 *_title；分类不进趋势。实体：患者档案、瘤体（编号/部位/测量方式）、测量事件、症状事件（疼痛 NRS/耳鸣）、听力事件、用药线与剂量变更、副作用事件、家系成员、随访项目打卡。
