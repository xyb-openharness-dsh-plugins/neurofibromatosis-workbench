## 一级路径（P0，窄 360 / 宽 ≥1024 双形态，30 号）
- IP1-就诊准备：入口 → 间隔期变化摘要（指标/症状/瘤体三节）→ 问题清单勾选 → 一页成稿（可复制/可带入 Agent 草稿）。
- IP1-随访日历：入口 → 当前年龄段分节展开 → 逐项打卡/补记录 → 异常项标记"待问医生"（仅标记，无判读）。
- IP1-瘤体档案：入口 → 瘤体列表（编号+部位）→ 选瘤体 → 尺寸折线 + 测量记录追加。
- IP1-指标系列：入口 → 分系列卡片墙（有序分组）→ 卡片 3D 翻转看背面详情 → 点折线进趋势页；一图秀弹指标选择窗口。

## 交互细节
- 折叠卡用 32 号模版（治疗线、随访日历年龄段节）；收/展两态均为验收态。
- 3D 翻转卡：正面=当前值+系列名；背面=参考语境+记录条数+最近三次；动画可被 reduce-motion 降级。
- 趋势折线：SVG root class="chart"，smoothPath 用 Fritsch–Carlson；分类项不进趋势。
- Agent：右侧面板（20 号），可拖宽 25–45%、可收；AI 按钮走 xxx:agent-draft（34 号）携带提示词+病情上下文。
- 患者红线：所有路径的核心产出都是患者要看的信息维度；任何"给医生看的判读面板"不得进入一级路径。
