## 与样板的结构性差异
- 纵轴不同：肿瘤样板以"治疗线+复查"为纵轴；NF 以"**年龄分段的终身日历**"为纵轴——家族首例。
- 聚合键不同：指标趋势按"瘤体编号"分曲线（多实体并行），样板按单患者单指标。
- 无分期系统：不引入 FIGO/TNM 类分期档案；用"分型 + 受累系统"替代（家族首例无分期病种之一，与地贫等慢病同类）。
- 遗传家系建档为家族首例模块。

## 一级重名率实测（M1 回填）
- 方法：取本仓 FEATURE-INVENTORY 一级名集合 A，cervical∪breast 一级名集合 B，重名率 = |A∩B| / |A|。
- 实测值：⏳ 待 M1；目标 ≤70%。
