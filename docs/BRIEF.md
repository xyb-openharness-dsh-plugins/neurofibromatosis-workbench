# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：神经纤维瘤病患者本人及家属照护者；NF1 患儿家长为代记主体之一，成年患者自助管理；NF2/施万细胞瘤病患者含听力减退线

场景：多系统受累导致不知道该挂哪个科、各年龄段该查什么；全身多发瘤体患者记不清哪个瘤在变化；NF2 听力逐年下降说不清过程；MEK 抑制剂治疗中皮肤/眼部副作用反复；家系成员想了解遗传咨询该问什么

核心流程：
1. 选择本机资料目录并导入影像/检验/听力报告
2. 核对候选信息，建立瘤体档案与基线指标系列
3. 按年龄段随访日历记录复查项目与结果
4. 记录疼痛、听力与用药线（含 MEK 抑制剂副作用）
5. 生成复诊与遗传咨询准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：分年龄段随访日历、瘤体尺寸档案与趋势、疼痛与听力时间序列、用药线与副作用记录、遗传咨询就诊问题清单；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
